# Inside Airbnb Dashboard

Dashboard Vue.js para visualização de dados do Airbnb em Portugal.

## Instalação e Execução

### 1. **Instalar dependências**

```bash
cd vue-dashboard
npm install
```

### 2. **Executar em modo desenvolvimento**

```bash
npm run dev
```

A aplicação será aberta automaticamente em `http://localhost:5173`

### 3. **Gerar build para produção**

```bash
npm run build
```

Os arquivos compilados estarão em `dist/`

### 4. **Preview da build de produção**

```bash
npm run preview
```

---

## 📁 Estrutura do Projeto

```
vue-dashboard/
├── src/
│   ├── App.vue          # Componente principal com o dashboard
│   ├── main.js          # Entrada da aplicação
│   └── style.css        # Estilos globais (Tailwind CSS)
├── index.html           # Arquivo HTML principal
├── package.json         # Dependências e scripts
├── vite.config.js       # Configuração do Vite
├── tailwind.config.js   # Configuração do Tailwind CSS
└── postcss.config.js    # Configuração do PostCSS
```

---

## 🛠️ Tecnologias Utilizadas

- **Vue.js 3** - Framework JavaScript
- **Vite** - Build tool moderno e rápido
- **Tailwind CSS** - Framework CSS utilitário
- **Lucide Vue** - Biblioteca de ícones SVG
- **PostCSS** - Processador CSS

---

## O que é KPI?

KPI significa "Key Performance Indicator" (Indicador‑chave de Desempenho). Neste dashboard, os KPIs são os cartões que mostram métricas importantes de forma resumida — por exemplo: total de listagens, preço médio, taxa de ocupação e anfitriões ativos.
